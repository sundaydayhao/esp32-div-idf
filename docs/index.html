首次安装

完整镜像从 0x0 烧录。无法自动连接时，按住 BOOT、点按 RESET，释放 BOOT 后重试。

日常升级

在设备的 SD / HTTP OTA 中选择应用镜像。V1 与 CYD 引脚不同，不能互刷；OTA 不接收完整合并镜像。

命令行烧录

python tools/firmware.py flash --board v2 --port COM7

将 COM7 替换为实际串口。独立 ZIP 包内另有 FLASH.txt 操作说明。

构建与镜像校验已完成；上电和外设验收需在对应实板上进行。详细接线见工程的 docs/HARDWARE.md。
